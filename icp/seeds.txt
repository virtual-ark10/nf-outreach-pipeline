# ICP seed domains for scripts/icp_research.py
#
# One domain per line. Sections set the segment, which drives the industry_fit score:
#   [signal_data]  a data/signal product is the company (score 3)
#   [enrichment]   contact/company enrichment data (score 2)
#   [infra]        scraping / data-acquisition infrastructure, talent data (score 1)
#
# Prefix a domain with "!" to keep it in the scan but never import it as a lead
# (anchor / reference account, or a company already spoken for elsewhere).
#
# Duplicates across sections are de-duplicated; the first section wins.
#
# Every domain here was verified to resolve to the intended company (homepage title check).
# A domain that yields no contacts is skipped by the scanner and NOT cached, so a provider
# gap or a saturated run simply retries next time instead of sticking for the cache TTL.
#
# This is a curated list, not autonomous discovery: the scanner only ever looks at what is
# written here. See the note on discovery in the pipeline skill.
